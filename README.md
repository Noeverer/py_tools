## ⚡ 功能特性

### 🤖 自动爬取
- 每日8-11点每小时自动爬取最新房源信息
- 智能识别房源变化并记录
- 支持多页数据抓取

### 📱 即时推送
- 通过Bark服务推送房源信息到iOS设备
- 支持个性化推送设置
- 包含房源名称、租金、户型、面积等关键信息

### 📈 数据分析
- 房源历史数据统计
- 租金趋势分析
- 区域房源热度排行
- 房型供需情况

### 🔔 专项监控
- 特定地点房源监控
- 特定房型监控
- 申请人数统计

## 🚀 快速开始

### 本地部署
1. 克隆项目
   ```bash
   git clone https://github.com/your-repo/py_tools-master.git
   cd py_tools-master/gzf_Spider
   ```

2. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```

3. 配置推送服务
   - 获取Bark推送密钥
   - 在`config/settings.py`中配置BARK_KEY

4. 运行爬虫
   ```bash
   python main.py
   ```

### 自动化部署
使用GitHub Actions实现定时自动运行：
- 配置`BARK_KEY`密钥
- 系统将按计划自动爬取并推送房源信息

## 📊 数据字段说明

| 字段 | 说明 |
|------|------|
| `house_name` | 房源名称/小区名 |
| `house_site` | 所属区域 |
| `rent` | 租金（元/月） |
| `house_type` | 户型（如：1室1厅） |
| `floor` | 楼层信息 |
| `area` | 建筑面积（平方米） |
| `applicant_count` | 申请人数 |
| `timestamp` | 数据获取时间 |
