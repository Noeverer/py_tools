# 📱 iPhone筛选快速开始指南

## 🎯 三种方式，选择最适合你的

---

## 方式1：快速筛选页面（最简单简单⭐⭐⭐⭐⭐）

### 访问地址

```
https://noeverer.github.io/py_tools/quick.html
```

### 特点
- ✅ 单屏设计，无需滚动
- ✅ 大按钮，易于点击
- ✅ 一键启用常用筛选
- ✅ 显示当前启用状态

### 使用方法
1. 在iPhone上打开上面的链接
2. 点击对应按钮启用/禁用筛选
3. 完成！配置自动保存

### 收藏到主屏幕
1. 在Safari中打开链接
2. 点击分享按钮
3. 选择"添加到主屏幕"
4. 下次一键打开

---

## 方式2：Bark推送操作（最便捷⭐⭐⭐⭐⭐）

### Bark深链接操作

在Bark推送中点击以下链接快速操作：

#### 快速启用筛选
```
https://noeverer.github.io/py_tools/quick.html?action=enable&filter=金桥低价
```

#### 快速禁用筛选
```
https://noeverer.github.io/py_tools/quick.html?action=disable&filter=金桥低价
```

#### 一键全启用
```
https://noeverer.github.io/py_tools/quick.html?action=enable-all
```

#### 一键全禁用
```
https://noeverer.github.io/py_tools/quick.html?action=disable-all
```

### 特点
- ✅ 无需打开Safari
- ✅ 直接从Bark消息中操作
- ✅ 深链接支持
- ✅ 操作即时生效

---

## 方式3：iOS快捷指令（最强大⭐⭐⭐⭐⭐）

### 导入快捷指令

1. 在Safari中打开快捷指令文件
2. 点击"添加到快捷指令"
3. 完成

### 可用快捷指令

- `启用金桥低价筛选.shortcut`
- `启用张江低价筛选.shortcut`
- `启用一室户优选筛选.shortcut`
- `禁用所有筛选.shortcut`
- `查看今日房源.shortcut`
- `快速筛选控制.shortcut`

### 配置Siri语音

1. 打开"快捷指令"应用
2. 选择快捷指令
3. 点击右上角图标
4. 点击"添加到Siri"
5. 录入语音指令

### Siri语音示例
- "Hey Siri, 启用金桥筛选"
- "Hey Siri, 禁用所有筛选"
- "Hey Siri, 查看今日房源"

### 添加到主屏幕
1. 长按快捷指令
2. 选择"共享"
3. 选择"添加到主屏幕"
4. 设置图标和名称

### 特点
- ✅ 集成到iOS系统
- ✅ 支持Siri语音控制
- ✅ 可添加到主屏幕
- ✅ 支持自动化

## 🆘 常见问题

### Q: 哪种方式最简单？

A: **快速筛选页面**（方式1）
- 无需任何配置
- 打开即用
- 操作简单

### Q: 哪种方式最强大？

A: **iOS快捷指令**（方式3）
- 集成到系统
- 语音控制
- 自动化支持

### Q: 可以同时使用多种方式吗？

A: 可以！各种方式可以组合使用，选择最适合当前场景的。

### Q: 配置会同步吗？

A: 所有方式共享相同的配置（localStorage），任何一种方式修改，其他方式都会生效。
