## 📥 导入方法

### 方法1: 通过Safari导入

1. 在Safari中打开快捷指令文件
2. 点击"添加到快捷指令"
3. 完成

### 方法2: 通过快捷指令应用导入

1. 打开"快捷指令"应用
2. 点击"+"号创建新快捷指令
3. 导入文件内容

### 方法3: 通过iCloud导入

1. 将`.shortcut`文件保存到iCloud Drive
2. 在快捷指令应用中从iCloud导入

## ⚙️ 配置Siri

### 为快捷指令设置Siri语音

1. 打开"快捷指令"应用
2. 选择快捷指令
3. 点击快捷指令图标（右上角）
4. 点击"添加到Siri"
5. 录入语音指令

### Siri语音示例

```
"启用金桥筛选"
"启用张江筛选"
"禁用所有筛选"
"查看今日房源"
```

## 🎨 自定义快捷指令

### 修改现有快捷指令

1. 打开快捷指令应用
2. 选择要修改的快捷指令
3. 点击右上角"编辑"
4. 修改参数或添加新操作
5. 保存

### 创建新的筛选快捷指令

复制现有快捷指令，修改URL参数：

```
https://noeverer.github.io/py_tools/quick.html?action=enable&filter=筛选名称
```

## 📊 快捷指令参数

### 启用筛选

```
action=enable&filter=筛选名称
```

### 禁用筛选

```
action=disable&filter=筛选名称
```

### 切换筛选

```
action=toggle&filter=筛选名称
```

### 一键全启用

```
action=enable-all
```

### 一键全禁用

```
action=disable-all
```

### 查看状态

```
action=status
```

## 🆘 常见问题

### Q: 快捷指令导入失败？

A: 请确保：
1. iOS系统版本≥13
2. 快捷指令应用已安装
3. 文件格式正确（.shortcut）

### Q: Siri无法识别语音？

A: 请检查：
1. Siri已启用
2. 已为快捷指令设置语音指令
3. 语音指令清晰明确

### Q: 快捷指令执行后无效果？

A: 请检查：
1. 网络连接正常
2. URL地址正确
3. 浏览器缓存已清理
