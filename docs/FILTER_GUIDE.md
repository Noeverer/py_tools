# 🎯 iPhone筛选使用指南

## 📱 快速开始

### 1. 访问筛选界面

在iPhone上打开以下地址：
```
https://noeverer.github.io/py_tools/filter.html
```

### 2. 启用筛选方案

- **快速筛选**：点击开关启用预设筛选方案
  - 金桥低价（金桥地区，月租<3000元）
  - 张江低价（张江地区，月租<3000元）
  - 一室户优选（一室一厅，月租<3500元）

- **自定义筛选**：设置自己的筛选条件
  - 选择区域（可选）
  - 设置最高租金
  - 选择户型（可选）

### 3. 预览筛选结果

点击"测试筛选"按钮，可以预览今日符合条件的房源：
- 显示总扫描房源数
- 显示符合条件的房源数
- 展示前5套房源详情
- 标记每个房源匹配的筛选方案

### 4. 保存配置

点击"保存设置"按钮，配置将在下次爬虫运行时生效。

## 🚀 功能特性

### 1. 预设筛选方案

| 方案名称 | 区域 | 租金 | 户型 |
|---------|------|------|------|
| 金桥低价 | 金桥 | <3000元 | 不限 |
| 张江低价 | 张江 | <3000元 | 不限 |
| 一室户优选 | 不限 | <3500元 | 1室1厅 |
| 唐镇低价 | 唐镇 | <3000元 | 不限 |

### 2. 自定义筛选

可以创建无限个自定义筛选方案：
- 区域筛选：金桥、张江、唐镇、曹路、陆家嘴、康桥
- 租金筛选：设置最高/最低租金
- 户型筛选：1室、2室、1室1厅、2室1厅等

### 3. 推送时间控制

默认推送时间段：
- 上午：8:00 - 11:00
- 晚上：19:00 - 21:00

只在这些时间段内推送房源信息。

## ⚙️ 配置同步

### 本地存储配置

筛选配置会保存在iPhone的浏览器本地存储中：
- 启用的筛选方案
- 自定义筛选条件
- 最后更新时间

### GitHub仓库配置

爬虫从以下文件读取配置：
- `gzf_Spider/config/filters.yaml` - 系统筛选配置
- `gzf_Spider/.env` - 环境变量配置

**注意**：iPhone上的配置需要手动同步到GitHub仓库。

## 📝 使用示例

### 场景1：只想要金桥的低价房源

1. 打开筛选页面
2. 启用"金桥低价"
3. 禁用其他筛选方案
4. 点击"保存设置"

### 场景2：想要一室一厅且租金低于4000元

1. 打开筛选页面
2. 点击"自定义筛选"
3. 区域选择"不限"
4. 最高租金输入"4000"
5. 户型选择"1室1厅"
6. 点击"添加自定义筛选"
7. 点击"保存设置"

### 场景3：想要张江和金桥的所有房源

1. 启用"金桥"筛选（不限租金）
2. 启用"张江"筛选（不限租金）
3. 点击"保存设置"

## ⚠️ 注意事项

1. **推送时间限制**：只在设置的推送时间段内推送
2. **配置生效时间**：配置在下次爬虫运行时生效（上午8:00、9:00、10:00）
3. **数据更新频率**：每天上午自动运行3次
4. **本地存储清理**：清除浏览器缓存会清除筛选配置

## 🆘 常见问题

### Q: 为什么收不到推送？

A: 检查以下几点：
1. 是否在推送时间段内
2. 是否至少启用了一个筛选方案
3. Bark推送是否正常工作
4. GitHub Actions是否正常运行

### Q: 如何查看历史推送？

A: 在Bark应用中查看历史消息，或在GitHub Pages查看历史数据。

### Q: 可以删除自定义筛选吗？

A: 当前版本需要手动删除系统配置文件中的自定义筛选。

### Q: 筛选条件多久生效？

A: 配置保存后，下次爬虫运行时生效（最多等待到下个运行时间）。
